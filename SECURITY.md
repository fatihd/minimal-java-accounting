# Security policy

## Supported versions

Only the current default branch is maintained. This repository is an
educational reference implementation and is not a supported accounting
product.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for sensitive findings. Do
not open a public issue containing credentials, exploit details, or private
data. Include the affected revision, impact, reproduction steps, and any known
mitigation.

The example configuration contains no usable credentials. Local passwords are
supplied through environment variables and must not be committed.
